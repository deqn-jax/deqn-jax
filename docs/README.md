# docs

Three kinds of documentation live here, each for a different reader.

| Folder | Reader | What it is |
|---|---|---|
| `site/` | contributors and users who need the details | the engineering site (mkdocs): installation, the model contract, networks, optimizers, the API reference |
| `dev/` | the maintainer and coding agents | the research record: the certification report, the program chronicle, the library review, the disaster model's specification, errata and LaTeX source (`dev/disaster/`), past audits (`dev/audits/`) |
| `superpowers/` | coding agents | design drafts and implementation plans written during agent sessions |

`composite_loss.md` and `figures/` are sources the engineering site includes.
Agents start from `AGENTS.md` at the repository root, not from here.
