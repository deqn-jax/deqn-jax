Write your own model

Anna Smirnova and Simon Scheidegger, University of Lausanne

The method is Deep Equilibrium Nets (Azinovic, Gaegauf & Scheidegger 2022; Scheidegger & Bilionis 2019).

A model is a folder of short Python files: variables and calibration, equilibrium conditions, and one object that ties them together. Below are the three files of the running example.

The example lives in src/deqn_jax/models/bm_labor_constrained/. It borrows from the uncapped model bm_labor everything the cap does not change: definitions, law of motion, steady state, starting distribution. Docstrings are omitted below.

Two labor numbersL_OUT_BOUND: the largest hours the rule can output. L_MAX: the cap \(\bar L\). At 1.02 the cap never binds; the run on the first page sets it to 1.

equations.py: the equilibrium conditions

src/deqn_jax/models/bm_labor_constrained/equations.py
from typing import Dict

import jax.numpy as jnp
from jax import Array

from deqn_jax.models._complementarity import fischer_burmeister
from deqn_jax.models.bm_labor.equations import definitions
from deqn_jax.models.bm_labor_constrained.variables import SPEC

EQUATION_NAMES = ("euler", "labor_foc")

EquationsOne condition per decision.

def equations(
    state: Array,
    policy: Array,
    next_state: Array,
    next_policy: Array,
    constants: Dict,
) -> Dict[str, Array]:
    beta = constants["beta"]
    delta = constants["delta"]
    psi = constants["psi"]
    theta = constants["theta"]
    L_max = constants["L_max"]

    p = SPEC.unpack_policy(policy)
    defs = definitions(state, policy, constants)
    next_defs = definitions(next_state, next_policy, constants)

Today and tomorrowInputs: today’s state and decisions, and tomorrow’s for one value of next period’s shock. Output: each condition as an error that is zero in equilibrium.

    u_c = defs["u_c"]
    w = defs["w"]
    u_c_next = next_defs["u_c"]
    mpk_next = next_defs["mpk"]

    euler = u_c - beta * u_c_next * (1.0 + mpk_next - delta)

Euler equation\(u'(C_t) - \beta\, u'(C_{t+1})(1 + r_{t+1} - \delta)\). Averaged over quadrature nodes for the shock it becomes \(u'(C_t) - \beta\,\mathbb{E}_t[\dots]\), so write the expectation linearly.

    slack = L_max - p.L
    wedge = w * u_c / (psi * jnp.power(p.L, theta)) - 1.0
    labor_foc = fischer_burmeister(slack, wedge)

    return {"euler": euler, "labor_foc": labor_foc}

The constraintSlack \(\bar L - L_t \ge 0\), wedge \(\mu_t \ge 0\), product zero: fischer_burmeister is zero exactly then (the code adds \(10^{-13}\) under the square root). The plain labor condition would have no zero at the cap.

Borrowed from bm_labor

From bm_labor/equations.py:

def definitions(state: Array, policy: Array, constants: Dict) -> Dict[str, Array]:
    s = SPEC.unpack_state(state)
    p = SPEC.unpack_policy(policy)

    alpha = constants["alpha"]
    gamma = constants["gamma"]

    Z = jnp.exp(s.z)
    # Cobb-Douglas: Y = Z * L^(1-alpha) * K^alpha
    y = Z * jnp.power(p.L, 1.0 - alpha) * jnp.power(s.k, alpha)

    # Factor prices
    mpk = alpha * Z * jnp.power(p.L, 1.0 - alpha) * jnp.power(s.k, alpha - 1.0)
    w = (1.0 - alpha) * Z * jnp.power(p.L, -alpha) * jnp.power(s.k, alpha)

    # Consumption via savings rate out of output
    c = (1.0 - p.sav_rate) * y
    sav = p.sav_rate * y

    u_c = jnp.power(c, -gamma)

    return {"Z": Z, "y": y, "mpk": mpk, "w": w, "c": c, "s": sav, "u_c": u_c}

From a copy to a solved model

  1. Copy the folder and replace bm_labor_constrained by the new name in the imports and in name=.

    cp -r src/deqn_jax/models/bm_labor_constrained src/deqn_jax/models/my_model

  2. Change SPEC, CONSTANTS, the bounds and equations. If you also copy files from bm_labor, point the imports inside the copies to your folder: dynamics.py otherwise keeps the old production function.

  3. Register it with two lines in src/deqn_jax/models/__init__.py:

    from deqn_jax.models.my_model import MODEL as _my_model
...
    "my_model": _my_model,

    Check with uv run deqn-jax info my_model.

  4. Copy configs/bm_labor_cap.yaml, set model: my_model and checkpoint_dir: runs/my_model, drop constants:, and train:

    uv run deqn-jax train --config configs/my_model.yaml

  5. Read the results: equation errors along a simulated path, and impulse responses.

    uv run deqn-jax evaluate runs/my_model/checkpoint_020000.eqx
uv run deqn-jax irf runs/my_model/checkpoint_020000.eqx --girf -o irf_out

    The evaluator’s errors are for one draw of next period’s shock and include its forecast error (about \(10^{-2}\) on the running example, against \(10^{-5.2}\) with the expectation taken). For the first page’s Euler error see expected_residuals in scripts/dev/econ_figures.py.

Everything else is in the reference: implementing a model and the full model contract.
