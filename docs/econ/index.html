Global solutions of dynamic stochastic models

deqn-jax solves a dynamic stochastic model from its equilibrium conditions and returns decision rules that hold across the states the economy visits, including the states where a constraint binds.

The running example on this page is the Brock–Mirman growth model with endogenous labor supply and an upper limit on hours worked. In good times households want to work more than the limit allows, so the limit binds in some states and not in others. A first-order perturbation is linear in the state and cannot represent such a constraint. A global solution can. In the simulation above the cap binds in 16% of periods; the linear rule of the uncapped economy exceeds it in 13% of the same periods.

The method is Deep Equilibrium Nets, introduced by Azinovic, Gaegauf and Scheidegger (2022) building on Scheidegger and Bilionis (2019). deqn-jax is a reimplementation and extension in JAX; the credit for the method belongs to those authors.

The idea in three pictures

1. What you write

You state the model the way it appears in a paper: the state variables, the decisions, the equilibrium conditions and the calibration. For the running example the whole model fits on one card.

States
capital \(K_t\) and log productivity \(z_t\)
Decisions
the savings rate \(s_t\), the share of output saved, and hours worked \(L_t\)
Preferences
\(\mathbb{E}_0 \sum_t \beta^t \big[\ln C_t - \psi \tfrac{L_t^{1+\theta}}{1+\theta}\big]\)
Technology
\(Y_t = e^{z_t} K_t^{\alpha} L_t^{1-\alpha}\), \(C_t = (1-s_t)\,Y_t\), \(w_t = (1-\alpha)Y_t/L_t\), \(r_t = \alpha Y_t/K_t\)
Law of motion
\(K_{t+1} = (1-\delta)K_t + s_t Y_t\), \(z_{t+1} = \rho z_t + \sigma \varepsilon_{t+1}\), \(\varepsilon \sim N(0,1)\)
Euler equation
\(\dfrac{1}{C_t} = \beta\, \mathbb{E}_t\Big[\dfrac{1 + r_{t+1} - \delta}{C_{t+1}}\Big]\)
Labor with a cap
\(L_t \le \bar L\), \(\mu_t \equiv \dfrac{w_t}{C_t\,\psi L_t^{\theta}} - 1 \ge 0\), \((\bar L - L_t)\,\mu_t = 0\)
Calibration
\(\alpha = 0.36\), \(\beta = 0.99\), \(\delta = 0.1\), \(\psi = 1\), \(\theta = 1\), \(\rho = 0.9\), \(\sigma = 0.04\), \(\bar L = 1\)

The labor condition is a complementarity condition. Either hours are below the cap and the usual first-order condition holds (\(\mu_t = 0\)), or hours are at the cap and the household would like to work more (\(\mu_t > 0\)). deqn-jax writes the three parts as one equation with the Fischer–Burmeister function, \(\sqrt{a^2+b^2} - a - b = 0\), which holds exactly when \(a \ge 0\), \(b \ge 0\) and \(ab = 0\). Both regimes are then zeros of the same equation. The second page shows the code.

2. The loop

The decision rule is a flexible function of the state with many coefficients. In a projection method that function would be a sum of Chebyshev polynomials; here it is a small neural network, which plays the same role of a basis whose coefficients are to be found. The coefficients are chosen to make the equilibrium conditions hold. At each simulated state the program evaluates the Euler equation and the labor condition, with the expectation over next period’s shock computed by Gauss–Hermite quadrature with eight nodes. The sum of squared errors is the objective, and the coefficients move a small step in the direction that reduces it. Then the economy is simulated again under the improved rule, and the loop repeats until the errors stop falling.

For the running example one round simulates 64 economies for 100 periods and takes 100 such steps. The solution on this page used 20,000 rounds.

3. Where the points come from

A projection method places its points on a tensor grid. With \(n\) points per state variable and \(d\) state variables the grid has \(n^d\) points: 100 for this model, ten billion for a model with ten state variables. Here the points are the states the simulated economy visits, so they sit where the economy spends its time, and their number is a choice that does not grow with \(d\). This is why models with many state variables remain feasible. The expectation over next period’s shocks still has to be computed at every point, and its cost grows with the number of shocks. The rule is accurate where the economy goes. Far outside the simulated cloud the rule is an extrapolation and should not be read as a solution.

Relation to familiar methods

All four methods look for the same object, a decision rule that satisfies the equilibrium conditions. They differ in how they represent the rule, where they ask the conditions to hold, and what that implies for constraints that bind only sometimes.

The example, solved

With uv installed, three commands fetch the code, install it and solve the running example:

git clone https://github.com/deqn-jax/deqn-jax
cd deqn-jax && uv sync
uv run deqn-jax train --config configs/bm_labor_cap.yaml

The configuration file names the model, sets the cap to 1 and fixes the size of the network and the number of rounds. On a laptop (Apple M4 Pro, CPU only) the run took about 15 minutes. The registered model sets the cap at 1.02, above the largest value the labor rule can take (1.01), so the cap never binds there; that calibration reproduces a course exercise, and the configuration file lowers the cap so that it binds.

Can you trust the answer?

The standard accuracy check for a solved model is the Euler-equation error (Judd 1992). At each state, take the consumption that would make the Euler equation hold exactly given the computed rule, and report its distance from the computed consumption as a fraction of consumption. A value of \(-3\) on the \(\log_{10}\) scale means an error of one dollar per thousand dollars of consumption.

Along the simulated path the median error is \(10^{ -5.2 }\) and the 99th percentile is \(10^{ -4.4 }\). The median error is \(10^{ -5.0 }\) in periods at the cap and \(10^{ -5.2 }\) in periods below it. The labor condition, written as the Fischer–Burmeister equation, has an absolute error no larger than \(2.7 \times 10^{-4}\) anywhere on the path.

The second check uses a model whose exact solution is known. In the stochastic Brock–Mirman model with log utility and full depreciation (\(\delta = 1\)) the optimal savings rate is \(\alpha\beta = 0.3564\) in every state (Brock and Mirman 1972). The same program, run on that model (model brock_mirman, configuration configs/brock_mirman_closed_form.yaml), returns a rule that can be compared with the exact one.

After 10,000 rounds the largest relative distance from \(\alpha\beta\) is \(3.5 \times 10^{-6}\) and the median is \(1.3 \times 10^{-6}\).

Two limits apply to every result produced this way.

A small equation error is necessary for a solution but not sufficient. A model can have more than one rule that satisfies its equilibrium conditions, and nothing in the method selects among them. The global analogue of the Blanchard–Kahn condition, which picks the stable solution of a linearized model, does not exist here. A low error says the computed rule is an equilibrium; it does not say it is the equilibrium you meant. Checks against a perturbation solution near the steady state, and against known special cases like the one above, help.

Accuracy is measured. The numbers above describe the states the simulation visited. They are not bounds that hold everywhere, and they say nothing about states outside the simulated cloud.
